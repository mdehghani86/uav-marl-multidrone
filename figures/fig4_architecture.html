Figure 4. Attention-MARL policy network
Permutation-invariant over nodes (T) and drones (M). One set of weights serves any fleet size.
F = 9 node features (pos, type, visited, deadline, mask, bias) · d = 128 · 4 heads per attention layer · shared weights across all M drones
Figure 4. Node observations \(\mathbf{X}\) pass through a linear embed f₁ and two self-attention encoder layers f₂, f₃. The acting drone's state \(\mathbf{X}'\) (battery, elapsed time, position, active one-hot) is projected by g into a per-drone query token q₊. Layer f₄ cross-attends the query over the node embeddings and scores each node; the masked softmax emits the next action. One set of weights serves any M and N.
