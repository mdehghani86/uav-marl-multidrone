Key Findings

Five incremental design improvements move an attention-based MARL agent from a $-25\%$ deficit to a $+4.38\%$ lead over the strongest heuristic on the same scenario grid.

Battery-feasibility action mask

A two-step mask that requires "can return from this customer" eliminates the 1.78 crashes per episode the random policy commits and is the prerequisite for any RL policy to be deployable.

Per-customer cost-and-slack features

Exposing the seven quantities the action mask already evaluates internally — distance, energy fraction, time fraction, deadline slack, return margin, net payoff, nearest-other-drone distance — closes the gap to heuristics in a single step (+25 percentage points of reward).

BC warm start + dual-pool critic

Behaviour-cloning from auction-heuristic trajectories, plus a critic that pools both the full and the feasible-only node sets, plus reward-and-deadline-weighted potential-based reward shaping, lift the agent another +2.5 percentage points.

Inter-drone coordination feature

One additional per-customer channel — the distance to the nearest other drone — gives the agent the same contention signal an auction heuristic computes online. Pushes the lift to a final +4.38% over the best heuristic at 0 crashes.
